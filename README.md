**FINANTY**

Administración de Finanzas Personales

---

Plataforma web diseñada para centralizar, organizar y consultar los ingresos y gastos personales desde un único lugar.

---

**DESCRIPCIÓN DEL PROYECTO**

Finanty surge como una solución a la fragmentación financiera actual, en la que los movimientos económicos se distribuyen entre diferentes medios, como billeteras virtuales, tarjetas y efectivo.

La plataforma permite a los usuarios llevar un control detallado de sus movimientos económicos diarios mediante una interfaz sencilla e intuitiva, visualizaciones gráficas y herramientas para gestionar categorías y medios de pago.

Objetivos principales

- Registrar y consultar ingresos y gastos.
- Visualizar los movimientos económicos mediante gráficos.
- Organizar las transacciones a través de categorías.
- Gestionar diferentes medios de pago.
- Centralizar la información financiera en una única plataforma.

**RAMAS DE TRABAJO — GIT FLOW**

Para organizar el desarrollo colaborativo y mantener un flujo de trabajo ordenado, se utilizan las siguientes ramas en Git:

| Rama | Descripción |
| :--- | :--- |
| **develop** | La rama principal de trabajo diario. Acá vamos a ir uniendo todo el código de la app (HTML, CSS, JS, PHP y la base de datos). |
| **feature/docs** | Exclusiva para subir toda la documentación formal (el informe, el análisis y las preguntas). |
| **feature/diagramas** | Para guardar y subir todos los diagramas del proyecto (DER, DFD, etc.). |
| **feature/frontend** | Para las tareas relacionadas con la maquetación y las pantallas de la interfaz web. |
| **feature/backend** | Para los archivos en PHP, la conexión a la base de datos y los endpoints. |
| **feature/dailys** | Para ir subiendo las minutas, los registros o las notas de las reuniones diarias de Scrum. |

Flujo de trabajo

Las ramas "feature/*" permiten trabajar en funcionalidades o áreas específicas del proyecto. Una vez finalizados los cambios, estos se integran en "develop" para su revisión y, finalmente, en "main" para la entrega de la versión estable.
