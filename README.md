# Develop — Integración del Proyecto

Esta rama centraliza el trabajo diario del equipo y permite integrar los avances realizados en las distintas áreas de desarrollo de Finanty.

**Objetivo**

Unificar y probar los cambios de la aplicación web antes de incorporarlos a la rama estable "main".

**Contenido**

- Código HTML, CSS y JavaScript.
- Lógica del servidor en PHP.
- Integración con la base de datos MySQL.
- Avances y funcionalidades desarrolladas por el equipo.

**Flujo de trabajo**

Los cambios realizados en las ramas "feature/*" se integran en "develop" para su revisión y prueba.
