# Feature/Backend — Lógica del Servidor

Esta rama está destinada al desarrollo de la lógica del servidor y la comunicación con la base de datos de Finanty.

**Objetivo**

Implementar las funcionalidades necesarias para procesar la información y gestionar las operaciones de la aplicación.

**Contenido**

- Desarrollo de funcionalidades en PHP.
- Conexión y consultas a MySQL.
- Gestión de usuarios y movimientos financieros.
- Desarrollo de endpoints y procesamiento de solicitudes.
- Validación de datos y lógica de negocio.
