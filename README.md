# Feature/Dailys — Registro de Reuniones

Esta rama está destinada al registro y la organización de la información obtenida durante las reuniones diarias del equipo de desarrollo.

**Objetivo**

Mantener un seguimiento de los avances, las tareas realizadas y los temas pendientes durante el desarrollo de Finanty.

**Contenido**

- Minutas de reuniones.
- Registros de las Daily Scrum.
- Avances individuales y grupales.
- Dificultades identificadas.
- Tareas pendientes y próximos objetivos.
