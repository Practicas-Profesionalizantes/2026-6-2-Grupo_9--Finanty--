**Finanty - Administración de Finanzas Personales**

> Plataforma web diseñada para centralizar, organizar y consultar los ingresos y gastos personales desde un único lugar.

Descripción del Proyecto

Finanty surge como solución a la fragmentación financiera actual (billeteras virtuales, tarjetas, efectivo, etc.). Permite a los usuarios llevar un control detallado de sus movimientos económicos diarios mediante una interfaz sencilla, visualizaciones gráficas y gestión de categorías y medios de pago.

Stack Tecnológico

El proyecto está desarrollado con las siguientes tecnologías:
 * Frontend: HTML5, CSS3, JavaScript.
 * Backend: Java (Servlets/JSP o lógica de servidor).
 * Base de Datos: MySQL (Gestión relacional de usuarios, movimientos, categorías y medios de pago).

Estructura del Repositorio

Para mantener el proyecto organizado, la documentación y el código fuente se distribuyen en las siguientes carpetas principales:
/finanty-proyecto/
│
├── /docs/ <-- Documentación formal (informe, análisis y preguntas)
├── /diagramas/ <-- Diagramas del sistema (DER, DFD, CPM)
├── /src/ <-- Código fuente de la aplicación web (HTML, CSS, JS, Java)
└── README.md <-- Presentación y guía del repositorio

Ramas de Trabajo 

Para coordinar el desarrollo en equipo, utilizamos las siguientes ramas en GitHub:
 * main: Versión final y estable del proyecto (incluye el código definitivo y la documentación completa lista para entregar).
 * develop: Rama de integración donde unimos el trabajo diario de la aplicación web.
 * feature/docs: Rama exclusiva para el armado y subida de la documentación y análisis.
 * feature/diagramas: Rama para la gestión de los diagramas del sistema.
 * feature/frontend: Rama para el desarrollo de la interfaz visual y pantallas.
 * feature/backend: Rama para la lógica en Java y la conexión con la base de datos MySQL.
 * feature/dailys: Registro y notas de las reuniones diarias del equipo.
