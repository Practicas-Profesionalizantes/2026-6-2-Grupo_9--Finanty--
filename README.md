# Feature/Frontend — Interfaz Web

Esta rama está dedicada al diseño y desarrollo de la interfaz visual de Finanty.

**Objetivo**

Crear una interfaz clara, intuitiva y accesible que facilite la interacción de los usuarios con la plataforma.

**Contenido**

- Estructura de las páginas en HTML5.
- Estilos y diseño visual con CSS3.
- Interactividad mediante JavaScript.
- Maquetación de pantallas y componentes visuales.
